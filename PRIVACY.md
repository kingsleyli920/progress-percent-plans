# Privacy Policy

Effective date: August 20, 2026

Progress Percent Plans is a skills-only plugin. It provides written workflow instructions to ChatGPT and Codex and does not operate an external service.

## Data collection

The plugin does not collect, transmit, sell, or remotely store personal information, prompts, plan contents, files, analytics, identifiers, or usage telemetry.

## Authentication and network access

The plugin does not require an account, API key, OAuth connection, MCP server, cookie, or external network request.

## Host platform data

The host product may process plan and conversation data according to the host platform's own terms and privacy policy. Progress Percent Plans does not receive a separate copy of that data.

## Changes

Material changes to this policy will be published in this repository with an updated effective date.

## Contact

Privacy questions may be submitted through the repository's public issue tracker.
